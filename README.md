# Multilingual Mobile App Review Analysis

## Overview
This project explores a multilingual mobile application review dataset using Python to understand data quality, feature distributions, and preprocessing requirements for downstream analysis and machine learning.

## Objectives
- Perform data ingestion, cleaning, preprocessing, and exploratory data analysis (EDA).
- Assess data quality using automated profiling reports.
- Identify missing values, outliers, skewness, and feature distribution patterns.
- Apply feature encoding, StandardScaler, and Principal Component Analysis (PCA) as part of the preprocessing workflow.

## Technologies Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, scikit-learn, ydata-profiling
- **Environment:** Google Colab
- **Techniques:** EDA, data quality profiling, feature encoding, feature scaling, dimensionality reduction

## Workflow
1. **Data Ingestion:** Load the multilingual mobile app review dataset into a Pandas DataFrame.
2. **Data Cleaning:** Inspect and handle missing values, duplicates, and data inconsistencies as appropriate.
3. **Exploratory Data Analysis:** Examine data distributions, feature characteristics, and potential anomalies.
4. **Data Quality Profiling:** Generate automated profiling reports using ydata-profiling.
5. **Feature Preprocessing:** Apply suitable feature encoding and StandardScaler.
6. **Dimensionality Reduction:** Apply PCA to explore dimensionality reduction for downstream analysis.

## Repository Contents
- `multilingual_mobile_app_reviews.ipynb` — Google Colab containing the analysis and preprocessing workflow.

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Upload the dataset or configure the appropriate dataset path.
3. Install any missing dependencies.
4. Run the notebook cells in sequence.

## Project Outcome
Developed a structured data analysis workflow covering data quality assessment, exploratory analysis, and feature preprocessing to prepare data for further analytical and machine learning tasks.
